
Dimensionamiento y validación de un sistema fotovoltáico off-grid para una bomba de agua residencial de 0.5 HP

Jan 2025 – Feb 2025

Diseño de un sistema fotovoltáico off-grid para el funcionamiento de una bomba de extracción de agua residencial de 0.5 HP de uso diario en hogares de La Ballena - Huaquén (V Región, Chile).

- Diseño de sistema off-grid FV+Baterías.
- Extracción de datos reales mediante Explorador Solar.
- Simulación y validación en MATLAB.
- Cotización y presupuesto inicial del Kit FV.
